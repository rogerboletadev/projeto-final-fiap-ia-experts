Arquitetura

Como o Copilot funciona hoje e para onde ele vai. A regra que atravessa todas as etapas: a IA entende o pedido, o código faz a conta.

Fonte única

Os CSVs em data/ alimentam o site e o n8n. O build gera tudo a partir deles, então os dois nunca divergem.

IA só interpreta

Gemini ou Claude transformam o texto em JSON. Nenhum valor sai do modelo de linguagem.

Testado

15 testes automáticos cobrem o cálculo, os modelos X, Y e Z e o código que roda no n8n.

Os diagramas desta página vêm do README do projeto. Quando a arquitetura mudar em um novo MVP, basta atualizar o README e rodar o build.
