Conexão com o n8n

Cole a URL de produção do webhook, salve e teste. O chat passa a usar essa URL na hora.

Onde fica salvo: só neste navegador. Para valer para todos os visitantes, coloque a URL em web/config.js e publique de novo.

No n8n: use um nó Webhook (POST) e termine o fluxo com Respond to Webhook. Em Allowed Origins (CORS), coloque o endereço deste site. O chat envia { "chatInput": "...", "sessionId": "..." } e mostra o campo output da resposta.
